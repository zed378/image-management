# 00 - Getting Started

> Category: **Developer Documentation** (`docs/DEVELOPER/`) &nbsp;|&nbsp; Status: Draft specification &nbsp;|&nbsp; Owner: TBD

## Purpose

Specify getting started for the Image Management & Delivery Platform. The first page a new developer reads: what the platform does in two sentences, how to get an API key, and a link straight to the quickstart.

## Category Mandate

Documentation is treated as a product surface, not an afterthought: getting-started material, task-oriented guides, and reference material written for a developer integrating the platform into a consumer application for the first time.

## Key Topics To Specify

- The first page a new developer reads: what the platform does in two sentences, how to get an API key, and a link straight to the quickstart.
- Should get a developer from zero to one successful API call (upload + fetch a resized image) in under five minutes, with copy-pasteable code.
