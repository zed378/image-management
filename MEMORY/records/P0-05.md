## What was built

`packages/logger`:

- `createLogger({ service, version, level, destination? })` -- pino 10,
  JSON to stdout, ISO timestamps, level as a label, `err` serializer, and the
  redaction list applied to every line.
- `requestLogger(parent, { request_id, trace_id, span_id })` and
  `withTenant(logger, { tenant_id, project_id?, application_id? })` -- child
  loggers binding the correlation and tenancy fields once.
- `REDACT_PATHS` -- credential-shaped fields at the top level and one level
  down, plus the auth/cookie/api-key headers.
- `redactUrl(url)` -- the log-scrubbing helper the task asked for: replaces
  the values of `sig`, `s`, `signature`, `token`, `api_key`,
  `X-Amz-Signature`, `X-Amz-Credential`, `X-Amz-Security-Token`, keeps the
  path and the transformation parameters, drops any fragment.
- W3C trace context: `parseTraceparent`, `continueOrStartTrace`,
  `childSpan`, `formatTraceparent`, `newTraceContext`.

## Deviations from the spec

- **The trace-propagation middleware is not in this task.** The task asks
  for "a trace-ID-propagation middleware in the API Gateway", but the API
  Gateway's HTTP server is created by `P0-08`, which depends on this task.
  The primitives the middleware needs are built and tested here; the
  middleware itself, and the DoD clause "a request produces one correlated
  log line per service it touches, joinable by `trace_id`", are delivered
  and verified in `P0-08`.
- **Redaction has a stated depth limit.** pino redaction matches paths at
  fixed depth; this list covers top level and one level down. Rather than
  hide that, `logger.test.ts` pins it with a test showing a secret two
  levels deep is *not* redacted, and both logging documents say so. The
  rule remains "do not log credential-bearing objects"; redaction is the net.

## Decisions worth recording

- W3C `traceparent` chosen over a bespoke `X-Trace-Id`: it is what
  OpenTelemetry (`P7-03`) and every major CDN and proxy already speak, so
  adopting it now means `P7-03` changes the exporter, not the wire format.
- A malformed incoming `traceparent` starts a new trace instead of being
  propagated -- one of the rejection tests is a header-injection attempt.
